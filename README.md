# 💃 Rud-Api

![Mi logo](./assets/appicon.png)

Rud-Api es la Api principal donde todas los Rud-Desktop van a consultar para procesar las solicitudes requeridas de todos los modulos.

## 🌍 RoadMap

Esta Api se planteno a dia de **03/09/2026** ya que se busca una mejor optimizacion directa a las solicitudes directas de cada una de las empresas dentro de la corporacion (MP). Es decir es una linea directa a un servidor directo gestionando todo en un mismo lugar en vez de dejarle toda la carga proceso a Rud-Desktop.


A fecha de **07/09/2026** la entrada de Queues se establece el switch para identificar el reporte y poder proceder con el flujo programado correctamente para ese reporte segun sea el caso.
